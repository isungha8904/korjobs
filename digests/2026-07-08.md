## 📰 뉴스 (News)

> 전문용어는 괄호로 바로 풀고, "왜 중요한지"를 개발자 관점에서 설명합니다.

### 🚀 GPT-5.6 Sol / Terra / Luna 프리뷰 확정
- **무슨 일:** OpenAI가 GPT-5.6을 세 갈래로 나눠 공개했습니다. **Sol**은 `Terminal-Bench 2.1`(= 터미널에서 실제 명령을 쳐가며 작업을 끝내는 능력을 재는 에이전트용 벤치마크)에서 **SOTA**(= State-of-the-Art, 현재까지 나온 것 중 1등 성적)를 기록. **Terra**는 이전 GPT-5.5급 성능을 **2배 저렴한 비용**으로, **Luna**는 셋 중 가장 빠르고 싼 모델입니다.
- **용어 풀이:** `벤치마크` = 모델 실력을 같은 문제로 비교하는 시험 · `추론(inference)` = 학습이 끝난 모델이 실제로 답을 뱉는 과정, 여기서 API 요금이 나옴.
- **왜 중요:** 코딩 에이전트(터미널을 직접 조작하는 AI)의 성능 상한이 또 올라갔고, "성능은 비슷한데 값은 절반"인 Terra/Luna가 나오면서 **같은 기능을 더 싸게 서빙**할 수 있게 됩니다. 지금 붙여 쓰는 코딩 툴의 모델을 재검토할 신호. [🔗 출처](https://www.buildfastwithai.com/blogs/ai-news-today-july-6-2026)

### 🚀 Meta 'Muse Spark' 공개
- **무슨 일:** Meta가 `Muse` 모델 패밀리의 첫 모델 **Muse Spark**를 냈습니다. **네이티브 멀티모달**(= 텍스트·이미지 등을 처음부터 한 모델이 같이 이해) `추론(reasoning)` 모델로, **툴 사용**(= 계산기·검색·코드 실행 같은 외부 도구를 스스로 호출), **비주얼 CoT**(`Chain-of-Thought`, 생각의 사슬 = 답을 내기 전 단계별로 추론하는 과정을 이미지에도 적용), **멀티에이전트 오케스트레이션**(= 여러 AI 에이전트를 지휘자처럼 조율해 협업)을 지원합니다.
- **왜 중요:** "이미지도 보고, 도구도 쓰고, 여러 에이전트를 조율하는" 게 한 모델의 기본기가 되어가는 흐름. 멀티에이전트 앱을 설계 중이라면 선택지가 늘어납니다. [🔗 출처](https://www.buildfastwithai.com/blogs/ai-news-today-july-6-2026)

### 🚀 Let's build GPT: from scratch — Andrej Karpathy · 조회수 500만+ · ~1h56m
- **한 줄:** GPT를 파이토치로 밑바닥부터 한 줄씩 짜보며 "LLM이 대체 어떻게 다음 단어를 맞히는가"를 손으로 이해합니다.
- **핵심 포인트:**
  - ① **셀프 어텐션**(self-attention = 문장 안 단어들이 서로 얼마나 관련 있는지 가중치를 매겨 참고하는 구조)을 코드로 직접 구현 — 트랜스포머의 심장.
  - ② `토큰`(token = 모델이 다루는 텍스트 최소 단위, 대략 단어 조각) → 임베딩 → 예측까지 전체 파이프라인을 눈으로 따라감.
  - ③ 에이전트·RAG 시대에도 안 바뀌는 **기초 원리**라, 한 번 제대로 보면 최신 모델 뉴스가 훨씬 잘 읽힙니다.
- **이런 사람에게:** LLM을 "그냥 쓰기"에서 "원리 이해"로 넘어가고 싶은 중급 개발자. (수학이 부담되면 아래 CodeEmporium 먼저)
- [▶ 보기](https://www.youtube.com/@AndrejKarpathy)

### 🔧 100M+ Tokens/Day on My Home AI Server (RTX 6000 ×2 + vLLM + Agents) — Mukul Tripathi · 조회수 8.5만
- **한 줄:** 집에 둔 GPU 서버 한 대로 하루 1억 토큰 이상을 처리하는 **셀프호스팅** 실전기.
- **핵심 포인트:**
  - ① **vLLM**(오픈소스 LLM 추론 서버 = 모델을 빠르고 효율적으로 서빙해주는 엔진)으로 처리량을 끌어올리는 실측 세팅.
  - ② 여러 **에이전트**를 동시에 돌릴 때의 GPU 메모리·`배치(batch, 요청을 묶어 한 번에 처리)` 튜닝 감각.
  - ③ "OpenAI API 값이 부담될 때 직접 서빙하면 얼마나 나오나"를 실제 하드웨어로 보여줌.
- **이런 사람에게:** LLM 앱 비용을 고민하거나 온프레미스/사내 서빙을 검토하는 중급자.
- [▶ 보기](https://developereducators.com/best/vllm/)

### 🔧 Production AI Agents 실전 빌드 — Cole Medin
- **한 줄:** 데모용이 아니라 **실제 프로젝트에 살아남는 에이전트**를 프롬프트부터 배포까지 만드는 과정.
- **핵심 포인트:**
  - ① 에이전트에 **메모리**(대화·작업 맥락을 기억시키는 법)를 붙여 매번 처음부터 설명하지 않게.
  - ② `툴 콜링`(tool calling = AI가 코드 실행·검색 등 외부 기능을 스스로 호출)로 실제 일을 시키는 구조.
  - ③ "데모는 되는데 실무에선 왜 무너지나"의 격차를 메우는 실전 팁.
- **이런 사람에게:** 사이드 데모를 넘어 팀 프로덕션에 에이전트를 넣으려는 개발자.
